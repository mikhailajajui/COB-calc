# COB-xlsx

A formula-driven Excel port of the COB segmented mortgage / cost-of-borrowing
engine (see [`COB-ts`](../COB-ts), [`COB-py`](../COB-py)). No code required to
use it -- open `COB_Calculator.xlsx` and edit the blue input cells.

**New to the workbook? Start with [`MANUAL.md`](MANUAL.md)** -- a sheet-by-sheet
usage reference with cell-level tables and five worked examples using the data
already in the file.

See [`docs/new-req/005-excel-workbook.md`](../docs/new-req/005-excel-workbook.md)
for the design writeup (why Excel formulas needed a different approach than the
code engines, two real bugs the Python-engine cross-check caught, and how every
number in the workbook was verified).

## Regenerating the workbook

The `.xlsx` file is generated by `build_workbook.py` -- treat that script as the
source of truth; don't hand-edit formulas in the file (regenerate instead, or
your hand-edits will be lost on the next `build_workbook.py` run).

```bash
python3 -m pip install openpyxl   # if not already installed
python3 build_workbook.py [output_path]   # defaults to ./COB_Calculator.xlsx
```

## Verifying it

**Run `recalc.py` on a COPY, never on `COB_Calculator.xlsx` itself.**
`recalc.py` uses LibreOffice, which rewrites the file it's given in place --
and LibreOffice's xlsx writer re-serializes some style/number-format codes
differently than openpyxl does (harmlessly for LibreOffice itself, but we hit
a real case where the result made Microsoft Excel refuse to open the file
without a "repair" prompt: LibreOffice turned a clean `yyyy-mm-dd` date format
into `yyyy/mm/dd`, and a clean `$#,##0.00;($#,##0.00);-` money format into a
garbled quoted/escaped equivalent). The shipped file must stay pure `openpyxl`
output -- that's what real Excel expects and opens cleanly. openpyxl doesn't
write cached formula values, but that's fine: `fullCalcOnLoad` is on by
default, so Excel computes every formula itself the moment the file opens.

```bash
cp COB_Calculator.xlsx /tmp/verify.xlsx
python3 <path-to-xlsx-skill>/scripts/recalc.py /tmp/verify.xlsx 240
```

Should report `"status": "success"`, `"total_errors": 0`. A clean recalc proves
the formulas *evaluate*, not that they're *right* -- see the design doc for how
values were additionally cross-checked against `cob_calculator` (COB-py), by
reading the verified COPY's cached values with
`load_workbook(path, data_only=True)` (never the pristine shipped file, which
has none until opened in Excel).

## Sheets

- **README** -- legend and assumptions, inside the workbook itself.
- **Segments, LumpSums, Overrides, PMI_Costs** -- inputs for the segmented
  mortgage engine.
- **Schedule, Summary, YearlySummary** -- computed (don't edit).
- **PaymentFrequency, ExtraPayment** -- standalone single-loan calculators.
- **Points, Refinance, CompareTerms, LTV_DSCR, ARM_Reset, Fees_APR,
  DTI_Affordability** -- standalone calculators, each with its own inputs.
