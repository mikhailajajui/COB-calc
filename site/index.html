Same engine, three implementations

Not one engine with three front ends — three independent implementations of the same segmented-mortgage math, cross-validated row-for-row against each other during development, including against an independent lending-domain reference model.

Pick based on how you work

Want to poke at it without installing anything? Use the web calculator. Need the full feature set — DTI, APR, bank reconciliation? Use the Streamlit app. Prefer to own the math yourself in a spreadsheet you can edit and hand to someone else? Take the Excel workbook.
